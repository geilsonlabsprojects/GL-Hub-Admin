# Changelog

All notable changes to this project will be documented in this file.

## [1.2.0] - 2026-07-15
### Added
- Gerenciamento de Categorias, Banners, Destaques e Slides da Home.
- Sistema de reordenação de itens.
- Preparação completa para GitHub (README, LICENSE, CI/CD).
- Documentação técnica inicial.

## [1.1.0] - 2026-07-14
### Added
- Módulo de Gerenciamento de Aplicativos (CRUD completo).
- Módulo de Gerenciamento de Sites.
- Integração com ImgBB para upload de mídias.
- Utilitário de compressão de imagem no navegador.

## [1.0.0] - 2026-07-13
### Added
- Estrutura inicial do projeto com Vite e React.
- Integração com Firebase (Auth e Realtime Database).
- Dashboard com métricas básicas.
- Sistema de temas (Dark/Light).
- Sidebar e Topbar responsivas.
