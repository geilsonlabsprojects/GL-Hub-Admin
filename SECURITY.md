# Security Policy

## Supported Versions

Only the latest version of GL Hub Admin is currently supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.x | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue. Instead, send an email to **security@geilsonlabs.com** (replace with your actual contact if available).

We will acknowledge your report within 48 hours and provide a timeline for a fix.
